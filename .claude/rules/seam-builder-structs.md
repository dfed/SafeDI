# Seams: builder structs

Continues `seam-generation.md`.

A seam's builders of a hole type, both families together, take a builder struct where no place they reach forwards a value (a place whose case carries a forwarded value: every `Instantiator<T>` or `SendableInstantiator<T>` place, whatever `T` forwards, and an `ErasedInstantiator` or `SendableErasedInstantiator` whose forwarded type is not `Void`, `TypeDescription.forwardedTypeOfWrapper`) and none holds a seam's scope (an `.inner` case, the seam's own where its tree builds it again, or a `.fill` case): `SeamBuilderFamilies.declaresBuilderStructs(of:holesBySite:)`, recorded on each of the hole type's enums (`ScopeEnum.declaresBuilderStruct`) and builders (`Builder.takesBuilderStruct`); every other hole type, and every public mock's, keeps the closure over its enum. Each such enum declares, after its cases, payload structs and nested enums, `__safeDI_Builder<__safeDI_Built>` (`ReservedName.builderStructTypeName`, `builderStructGenericParameterName`): one stored function per case, named as the case, taking the case's payload struct, or, for a `@Sendable` enum's case, an empty `Sendable` struct named as a payload struct (`ScopeEnum.Case.memberValuesTypeName`), and returning `__safeDI_Built` for a place or the held enum's struct; its memberwise initializer; and `init(__safeDI_noScope __safeDI_builder:)`, every member of which calls the one builder. A `@Sendable` enum's struct is `Sendable` with `@Sendable` members. The enums, payload structs and structs of such a hole type are `nonisolated`. A hole type that keeps its closure over the enum gets none, a deliberate gap: its generated code is unchanged until it takes the struct. The generated-only initializer takes the root's struct (`Builder.parameterType`, which the guard hashes) and the readable one `() -> T` or `@Sendable () -> T` (`Builder.readableParameterType`, which the two diagnostics that print a builder's type print), passing `.init(__safeDI_noScope:)`. The seam's tree calls one member per step of a place's route (`RouteStep.Member`), bound `__safeDI_<builder label>_<case>` on the struct the step before returned, the root builder's for the first: before the step's property's builder function, as a payload is bound, or, for a `@Sendable` enum's step whose property is built in a `@Sendable` function, at the top of that function (`SeamHoles.memberCallsInsideFunction(at:)`), since what it returns can be a plain struct that function could not capture; the place calls its own member on the last. Each `@Sendable` local function of such a seam's tree is `@Sendable nonisolated` (`ScopeGenerator.localFunctionPrefix(isSendable:isNonisolated:)`). A loop's level re-entered through a cycle-closing scope re-enters the function built at its first opening, with the struct bound there, as the enum form re-enters with that payload; the member at the reopening property that would carry what was bound above it is not generated yet, a deliberate gap kept safe by `declarationBoundOnCycleReentry`, which rejects every read whose value would differ.

A caller writes, for each enum a builder struct's root reaches, a function that returns the level's struct (`FillDispatcher.returnsBuilderStruct`, keyed apart from the enum-form dispatcher of the same enum, `FillDispatcher.key(of:returnsBuilderStruct:)`), taking the values its targets read that the cases do not carry, its members calling the next level's function, a fill by name, or holding an inlined fill's body, which declares no function (`ScopeGenerator.fillDeclaresFunction`; one that does is called by name, since a function declared inside the struct's closure would not take the isolation of the code around it), and the call passes the root's function called. An enum the call reaches only as the value a kept case carries keeps its dispatcher, and so does every enum of a hole type that a call inside the call's fills reaches through a kept builder (a seam that passes the called seam's place up, whose case carries the called seam's enum): that call reuses the dispatchers, which hand the fill what a case on the way carries, so the call hands the struct-taking seam their conversion (`builderKeysHandedInEnumForm(byCallsInside:calling:)`). Where a kept seam's call hands a struct-taking seam's enum on (a pass-up closure, or dispatchers that keep their enum form to carry the scope the call hands its fills, `SeamHoles.innerScope(at:innerKey:)`), the call passes a struct whose members rebuild the case around the values each was handed and hand it on (`ScopeGenerator.builderStructConversion(ofEnumOf:enumsByKey:builtType:reservedNames:names:handing:)`): one expression where no enum the root reaches holds one open on its route again, and else one function per level a route first opens, each taking the wrap that turns its level's case into the root's and the wraps of the open levels a member beneath it reopens, a reopening member calling the reopened level's function with the wrap it was first given, so no value is wrapped twice.
