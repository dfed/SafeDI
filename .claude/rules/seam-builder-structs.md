# Seams: builder structs

Continues `seam-generation.md`.

A seam's builders of a hole type, both families together, take a builder struct whatever places they reach (an `.inner` case, the seam's own where its tree builds it again, or a `.fill` case): `SeamBuilderFamilies.declaresBuilderStructs(of:)`, recorded on each of the hole type's enums (`ScopeEnum.declaresBuilderStruct`) and builders (`Builder.takesBuilderStruct`); every public mock's keeps the closure over its enum. Each such enum declares, after its payload structs and nested enums, `__safeDI_Builder<__safeDI_Built>` (`ReservedName.builderStructTypeName`, `builderStructGenericParameterName`): one stored function per case, named as the case, taking the case's payload struct, or, for a `@Sendable` enum's case, an empty `Sendable` struct named as a payload struct (`ScopeEnum.Case.memberValuesTypeName`), and returning `__safeDI_Built` for a plain or lazy place, the erased wrapper's `Builder` over it for a place held in an instantiator (`ErasedInstantiator<F, __safeDI_Built>.Builder`, `SendableErasedInstantiator` in a `@Sendable` enum, `F` the forwarded value the case carries, or `()`), or the held enum's struct; its memberwise initializer; and `init(__safeDI_noScope __safeDI_builder:)`, every member of which calls the one builder. A `@Sendable` enum's struct is `Sendable` with `@Sendable` members. The enums, payload structs and structs of such a hole type are `nonisolated`. A hole type that keeps its closure over the enum gets none, a deliberate gap: its generated code is unchanged until it takes the struct. The generated-only initializer takes the root's struct (`Builder.parameterType`, which the guard hashes) and the readable one the type its places' forwarded values give it (`Builder.readableParameterType`, from `DependencyTreeGenerator.builderForm(ofPlaces:)`, which the two diagnostics that print a builder's type print): `() -> T` or `@Sendable () -> T` where every place is plain or lazy, or forwards nothing beside such a place, else the wrapper's `Builder` or its `Sendable` twin's, or the erased wrapper's where the places spell one value through other wrappers or spellings, over the most explicit of their spellings (`TypeDescription.mostExplicitSpelling(among:)`: the longest name-erased spelling, `withNamesErased`, then its text, then the spelling's), never by where the places are, since a location's file path is a name; the location order (`sortedByForwardingLocation`) chooses only which place an error about other forwarded values names; passing `.init(__safeDI_noScope:)`. The seam's tree calls one member per step of a place's route (`RouteStep.Member`), bound `__safeDI_<builder label>_<case>` on the struct the step before returned, the root builder's for the first: before the step's property's builder function, as a payload is bound, or, for a `@Sendable` enum's step whose property is built in a `@Sendable` function, at the top of that function (`SeamHoles.memberCallsInsideFunction(at:)`), since what it returns can be a plain struct that function could not capture; the place calls its own member on the last. Each `@Sendable` local function of such a seam's tree is `@Sendable nonisolated` (`ScopeGenerator.localFunctionPrefix(isSendable:isNonisolated:)`). For a place held in an instantiator, the seam builds the wrapper around its member's result, `Instantiator<T>(<struct>.<member>(<values>))`, with no builder function of its own for the place. The struct's no-scope initializer is typed per level by the places at and beneath it, in the level's family, and adapts a builder of another form: `{ _ in { _ in __safeDI_builder() } }` for an instantiator member under a builder that takes nothing, and `{ _ in { _ in __safeDI_builder(()) } }` for a member forwarding `T.ForwardedProperties` under a builder of `()`; a level member of another form is handed `.init(__safeDI_noScope:)` of the same adapter. A caller fills such a place with a place function, `<level function>_<member>`, which takes each field of `values` the fill reads and the reads handed down, declares the fill's builder function inside it, and returns `{ forwarded in <builder function>(…) }` as the wrapper's `Builder` (spreading a labeled tuple by label, `{ _ in … }` where the fulfiller forwards nothing), so the closure the wrapper keeps captures no `values`. A kept seam that converts such a member hands `{ v in { forwarded in E(wrap(.case(v, forwarded))) } }`, `{ _ in … }` where the case has no values, and `{ … in { _ in … } }` where it carries no forwarded value (`placeValue(of:rebuilt:)`). A loop's level re-entered through a cycle-closing scope re-enters the function built at its first opening, with the struct bound there, as the enum form re-enters with that payload; the member at the reopening property that would carry what was bound above it is not generated yet, a deliberate gap kept safe by `declarationBoundOnCycleReentry`, which rejects every read whose value would differ.

A caller writes, for each enum a builder struct's root reaches, a function that returns the level's struct (`FillDispatcher.returnsBuilderStruct`, keyed apart from the enum-form dispatcher of the same enum, `FillDispatcher.key(of:returnsBuilderStruct:)`), taking the values its targets read that the cases do not carry, its members calling the next level's function, a fill by name, or holding an inlined fill's body, which declares no function (`ScopeGenerator.fillDeclaresFunction`; one that does is called by name, since a function declared inside the struct's closure would not take the isolation of the code around it), and the call passes the root's function called. An enum the call reaches only as the value a kept case carries keeps its dispatcher, and so does every enum of a hole type that a call inside the call's fills reaches through a kept builder (a seam that passes the called seam's place up, whose case carries the called seam's enum): that call reuses the dispatchers, which hand the fill what a case on the way carries, so the call hands the struct-taking seam their conversion (`builderKeysHandedInEnumForm(byCallsInside:calling:)`). Where a kept seam's call hands a struct-taking seam's enum on (a pass-up closure, or dispatchers that keep their enum form to carry the scope the call hands its fills, `SeamHoles.innerScope(at:innerKey:)`), the call passes a struct whose members rebuild the case around the values each was handed and hand it on (`ScopeGenerator.builderStructConversion(ofEnumOf:enumsByKey:holesBySite:builtType:reservedNames:names:handing:)`): one expression where no enum the root reaches holds one open on its route again, and else one function per level a route first opens, each taking the wrap that turns its level's case into the root's and the wraps of the open levels a member beneath it reopens, a reopening member calling the reopened level's function with the wrap it was first given, so no value is wrapped twice.

A seam's enum that declares a builder struct is a namespace with no case and no `@frozen` (`ScopeGenerator.scopeEnumDeclaration`'s `isSeam`). A public mock's enum keeps its cases and `@frozen` even where it declares a struct, a deliberate gap: its callers' conversions and dispatchers still build and switch over those cases. The change that removes those callers widens the rule to public mocks; both sites say so.

A fill that holds places of several hole types or families of the calling seam is handed one struct of its own level per type (`SeamHoles.innerScopes(at:innerKey:)`), each named `__safeDI_<call>_<builder>_<label of the builder whose route leads there>` (one alone keeps `__safeDI_<call>_<builder>`), and each level function on the call's carried route takes the caller's struct of its level once per type, in the order of the fill's parameters' names, which the fill and every level function declare and are called with (`FillDispatcher.carriedInnerScopes`), each under `up_` and the fill's parameter's name without its `__safeDI_` prefix (one alone under `up`): a positional name would move to another type when the types are renamed. Each is claimed apart from every label a carried level's cases hold, which a level function takes as values beside it, without reserving those labels.

A fulfilling call that hands up its plain enum from a `@Sendable` fill is a plain place to the place graph (`SeamDeclarationGraph.placeHolding`): the fill's edge already says the call is built in that function, so the fill's case is of the `@Sendable` family and holds the plain enum, as a child call's own case does.

The error about a declaration a seam binds on its path to calls whose places it passes up (`boundByPassingUpSeam`) takes every part a place decides from every place it names: the seams whose calls present them, the builders, and each remedy, once per kind of place (built in a `@Sendable` function or not). Two findings of one reader that differ only in their places merge into one that names both (`FillFinding.adding`), so no place is picked by where it is declared. In the same form, the error about a declaration on the path to a call inside a fill that re-enters the seam (`declarationBoundOnPathToReenteringCall`) names every path that hides the label (`FillReentryHidings.pathDeclarations` keeps each path's), one clause per declaration and call in name order, since which fill's path a walk meets first follows the order of the files that declare the places.
