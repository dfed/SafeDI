# Graph fuzzer: the query oracle

`query graph` exports, for each received dependency and alias, the declarations whose values generated code hands it, and whether and why it hands `nil` (`provenance`; `query-needs.md`). The query oracle (`GraphFuzzerToolRuns.querySuppliersFailure`, `Tests/SafeDIToolTestSupport/GraphFuzzerQuerySuppliers.swift`) checks that claim on every graph in one module the tool accepts, base corpus and seam corpus alike, but a public mock's graph: `toolRuns(of:)` exports the fixture's files with `QueryGraph` (`GraphFuzzerQuerySupplies.export(of:)`), reading an export whose `completeness` is `trees`, each `nil` entry as `nil` whatever its reason, and each dependency's kind from its `source`, `lifetime` and `aliasOf` (`kindsByLabelByType(exportedJSON:)`), and the oracle reads the generated production code's syntax (`GraphFuzzerQuerySupplies(generatedFiles:kindsByLabelByType:)`), never SafeDI's own resolution. For each construction of a type the export lists (`T(…)`, `T.instantiate(…)`, a root's `self.init(…)`, a nested type by its qualified or bare name), each argument of a received or aliased dependency is resolved as Swift scopes its name: the nearest `let` before it in an enclosing block, or a parameter of an enclosing function. A `let` of a label its function's type instantiates, forwards or aliases is that supplier (the type a builder function returns, or the root an `init` extends); the receive's own alias is followed to what it renames, through an erasing wrapper (`AnyT(x)`, or `(x as T?).map { AnyT($0) }` for an erased rename of an optional), and `.instance`; a `let` its type does not declare is a builder loop's rebinding, read where the function is declared; a function parameter its type forwards is that supplier, and any other is a lazy cycle's parameter, followed to the argument of every call of that function; `nil` is `nil`. Mock code (`#if DEBUG`, `…Mock…` files) is skipped. The two sets must be equal for every receive, and every read must resolve (`querySuppliersDifferFromGeneratedCode`). At least ten smoke graphs must be judged (`smokeSeeds_judgeQuerySuppliers_inGraphsTheToolAccepts`). A graph with a seam is judged on its build with no seam (`inlineOutcome`): the export builds every seam inline, and `seamBuildsOtherValuesThanInline` equates the seam build's values with the inline build's. With the walk handing every receive its nearest declaration whatever `unavailableProperties` says, base corpus seed 2 fails (`S2_T1.t2Builder`); with no call passing `nil` judged (`OmissionFindings.passedNothing`), `SafeDIToolQueryGraphTests.graph_recordsNilProvenance_whenLazyCyclePassesNilFromOneCall` fails.
