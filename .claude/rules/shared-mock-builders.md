# Builders shared by a module's mocks

A place of a type whose internal mock the module generates is built by `static func __safeDI_build_<hash>` in that type's extension, which every mock of the module that builds the place alike calls, instead of a builder function of its own in each mock (`MockLowering+SharedBuilders.swift`). The function is the type key's layout of the place alone (`TypeKeyBody.staticFunction(building:parameters:attributes:)`), lifted out of each root's body before it is spelled (`SharedBuilderLifting`, from `typeKeyRootLines`).

- **Which places.** Decided at walk time, per place (`Walk.sharedBuilderAttributes(of:instantiable:isLoopMember:)`): the type has an internal mock of this module (`MockContext.sharedBuilderAttributesByType`; a `.public` mock's type has none); it is not generic; neither its construction initializer nor its hand-written mock is `nonisolated`, which a static function of the type's isolation could not call as the mock's body does; and the place's builder function reads nothing a function apart from the mock's body could not: no loop of builders, no `@Sendable` function or actor's argument (whose overrides are read into locals first), no configuration a repeated ancestor reads, no filled call's builders; and its subtree is closed (`SubtreeSharing.isClosed(atNode:)`, remembered per generator in `closedSubtrees`). Anything else stays in the mock's body, as before. A place is lifted even where only one mock builds the type.
- **Cost.** The lifting recurses through `async` functions, whose frames the task holds, since a mock's tree can be as deep as the module has types (`SafeDIToolDeepTreeTests`' chains of 1,500). What each place's function reads from outside it, and what it is handed and reads, are found once per plan node, children before parents on an explicit stack, and a place rebuilt around lifted places is rebuilt once per plan node, attributes and declarations of the labels it reads from outside (`RebuildContextKey`), so a node reached along many paths costs one lifting per context.
- **Attributes.** The function takes the built type's `mockAttributes`, and a place is lifted only where those are empty or equal the attributes of the code that calls it (the calling mock's, or the shared builder the place is built in), so a builder whose attributes name an isolation is called only from code that spells the same.
- **The name.** `ReservedName.sharedBuilder(named:)` hashes the declaration with 64-bit FNV-1a, line by line with a `0xFF` after each, leaving out `#sourceLocation` lines, and spells 16 uppercase hex digits, the format of a seam's guard. So the name follows only the code: not the file paths `#sourceLocation` names, which differ between integrations, nor which root lowered the place first. The macro target compiles `ReservedName.swift` alone, so the hash is written out there rather than calling `SeamSignatureHash`.
- **Placement and merge.** Builders are merged per (type, name) across roots and declared in the built type's mock file after the mock and before its `SafeDIMockConfiguration`, each in an `#if <mock condition>` extension of its own: their order is by name, and a name's hash follows the type names in the declaration, so two builders of one type in one extension would swap under a renaming, while the order of extensions in a file, as of the configurations, tells nothing (the rename oracle's `GraphFuzzerExtensionOrder`; seam smoke seed 605 holds two builders of one type). Two declarations of one name differ at most in their `#sourceLocation` lines; the one first by UTF-8 is kept, so no root order decides the bytes.
- **The value oracle.** The value oracle's run adds root mocks whose places bring builders into a type's file that the drawn graph's run does not declare; R6 removes those before comparing (`GraphFuzzerMockOverrides.removingSharedBuilders(notDeclaredIn:from:)`, `fuzzer-value-oracles.md`).
- **The draw.** `addingMockedTypeTwoMocksBuild` (`fuzzer-corpora.md`) and `sharedMockBuilderFailure` check that a mocked type reached from two mocks, one with other attributes, a `nonisolated` initializer, or an unmocked type between, is built through exactly one shared builder where it may be and inline where it may not.
