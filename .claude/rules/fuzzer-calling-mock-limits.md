# Graph fuzzer: the calling-mock check's limits

The known issues, cost, undrawn shapes and report-only run of the calling-mock check and draw that `fuzzer-calling-mocks.md` and `fuzzer-calling-mock-draw.md` describe, and the draw's blocks from `970..<1030` on, which that file has no room for.

## Blocks from `970..<1030` on

- **`970..<1030`, a fill that constructs a type the caller's module cannot reach** (`fillConstructsTypeCallerModuleCannotReach`): the shape of block `910..<970`'s fill, or `Part` beneath it, instantiates a protocol only an `internal` type of the outer module in the caller's package, or a `package` one of another package, fulfills, or a `public` one whose hand-written mock alone is `internal` (`UnreachableConstruction`); half its graphs compile the generated mocks, where the mock reports the twin's access errors at its sites, or, for that mock, which the twin does not call, its own error (`expectedMockOwnErrorSite`), and the others pass the place up (`holeBuilderLabel`); `fillConstructsTypeCallerModuleCannotReachDraw_drawsEachVariation_inPinnedNumberOfGraphs` pins each variation, seeds 970 and 977 (the mock's own error) fail with the place passed up, and seed 971 with the fill made in every build.
- **`1030..<1090`, a value nothing provides** (`calledTypeReceivesValueOnlyIfAvailableNothingProvides`, every caller and place): the caller's own value's shape, whose called type, or `Gauge` beneath it (`ValueNothingProvides`, drawn after everything else, and only for that shape), receives only if available a value no declaration provides. The twin's seam takes it as a parameter (`expectedTwinInitializerLabels`), and the calling mock takes it too, an internal or listed one as a `SafeDIOverrides` entry and a `.public` one as a parameter (`flatParameterLabels`), so the probes hand it a value through each and compare the mock with the twin. No call there is inside a `@Sendable` function, where an internal mock takes no such entry (`mock-generation.md`), which `SafeDIToolCallingMockOnlyIfAvailableOverrideTests` covers. `calledTypeReceivesValueOnlyIfAvailableNothingProvidesDraw_drawsEachVariation_inPinnedNumberOfGraphs` pins each receiver, caller and place, and seed 1030, its first, fails with the internal mock's override reverted, when its probe does not compile (`callingMock_passesOverrideToCall_whenDrawnCalledTypeReceivesValueOnlyIfAvailableNothingProvides`).

- **`1090..<1120`, a lazy place** (`calledTypeHoldsPlaceLazily`, every caller, a plain place only, since the wrapper is the place's deferral): the caller's own value's shape whose called type holds its place in a `LazilyInstantiated` or `SendableLazilyInstantiated`, now and then beside a place of the hole by value before it, which one fill fills (`LazyPlace`, drawn after everything else, and only for that shape, from the graph's index in its cell, `graphIndexInCell(ofSeed:)`, so each value of thirty graphs keeps ten). A `SendableLazilyInstantiated` builds its place in a `@Sendable` function, handed no value of the caller, so there the fill reads nothing, in production too (`fillReadsValue`). The twin and the mock fill every place, and the probes compare the mock with the twin. `calledTypeHoldsPlaceLazilyDraw_drawsEachVariation_inPinnedNumberOfGraphs` pins each wrapper, the place beside it and each caller, and seed 1090, its first, fails with a hole whose property is a lazy wrapper left unfilled in `holesFilled`, its mock then passing up `feedServiceBuilder` unclassified (`callingMock_fillsLazyPlaceAsTwin_whenDrawnCalledTypeHoldsPlaceLazily`).
- **`1120..<1180`, a second hole type** (`calledTypeHoldsSecondHoleType`, every caller and place): the same shape whose called type also holds a place of `MeterService`, before or after the first hole's, which `LiveMeter` of the caller's module fills reading the caller's value or nothing, or which no type the caller's module sees fills, so the twin and the mock take `meterServiceBuilder` (`SecondHole`, drawn after everything else, and only for that shape; `expectedTwinInitializerLabels`, `expectedPassUpLabels`), whose probe hands it `MeterStub`. `calledTypeHoldsSecondHoleTypeDraw_drawsEachVariation_inPinnedNumberOfGraphs` pins each fill, position, caller and place, and seed 1120, its first, fails with only the first hole type of each call filled, its mock then passing up `meterServiceBuilder` unclassified (`callingMock_fillsSecondHoleTypeAsTwin_whenDrawnCalledTypeHoldsSecondHoleType`).
- **`1180..<1240`, a caller that forwards the value its fill reads** (`callerForwardsValueFillReads`, every caller and place): the caller forwards `database`, which the fill reads, required or only if available (`ForwardedValue`, drawn after everything else, and only for that shape); the twin fills the place from its forwarded value and the mock, of every caller kind, from the parameter its `mock()` takes for it (`flatParameterLabels`), which the probes hand one value. `callerForwardsValueFillReadsDraw_drawsEachVariation_inPinnedNumberOfGraphs` pins each read, caller and place, and seed 1180, its first, fails with a fill that receives anything beside its place's fields passed up, its mock then passing up `trackerServiceBuilder` unclassified (`callingMock_fillsPlaceFromForwardedValue_whenDrawnCallerForwardsValueFillReads`).
- **`1240..<1270`, a place instantiated only if available** (`placeInstantiatedOnlyIfAvailable`, every caller, a plain place only, since the place is an optional by value): the called type declares `@Instantiated(onlyIfAvailable: true) let p: (any P)?`, and the caller's module declares a type that fulfills `P` in half the graphs (`OptionalPlace`, from the graph's index in its cell). Where it does, the twin and the mock fill the place; where it does not, both take `pOptionalBuilder` (`holeBuilderLabel`), the mock's defaulting to `{ nil }`, which the probe hands the twin's. `placeInstantiatedOnlyIfAvailableDraw_drawsEachVariation_inPinnedNumberOfGraphs` pins each half and caller, and seeds 1240 and 1243, the first of each half, fail with the called public mock binding the place `nil` in place of taking a builder for it (`callingMock_fillsPlace_whenDrawnPlaceInstantiatedOnlyIfAvailableWithVisibleImplementation`, `callingMock_passesUpOptionalBuilder_…WithoutVisibleImplementation`).
- **What these four compare.** The cell test compares, beside the first graph of each cell and leaf position, the first with each variation of these shapes, keyed by shape and variation rather than by cell, since the leaf position already varies the caller (`comparedSeeds`): 47 graphs of the first three's 150, all of which state probes, and the first graph of each half of the fourth's.
- **Known issues.** `SafeDIToolGraphFuzzerCallingMockTests.callingMockKnownIssues` lists one entry per cell that fails, and is empty: every cell passes, the seam built again's by building what inline builds. A listed seed that passes is reported stale, except one whose every signature is `.callingMockDoesNotCompile` in a run with compile verification off, which compiles nothing. Each entry lists seeds of one shape cell, never the control's, in increasing order (`callingMockKnownIssueListProblems`), and no count is required, so a fix deletes the seeds and entries it mends and nothing else. The hand-written tests pin each shape's twin sites, require the twin's intended outcome and that the mock mirrors it; the seam built again's test (`callingMock_buildsInlineValues_whenFillReadsValueOfLevelBetweenBuildsOfSeam`) also requires that the twin's error is recognized as that outcome, and compares the mock's values with inline's, and `callingMock_compiles_whenFillReadsValueOfLevelBetweenBuildsOfSeam` compiles its mock. The twin's seam initializer labels are read from the initializers of an extension of the caller itself, never of a nested type such as a seam enum's builder struct.
- **Cost.** In the ordinary suite the check compiles only in `callingMock_compiles_whenFillReadsValueOfLevelBetweenBuildsOfSeam` (a compile per module), in the value tests `callingMock_buildsTwinsValues_whenFillReadsNothing`, its deferred twin, `callingMock_buildsInlineValues_whenFillReadsValueOfLevelBetweenBuildsOfSeam` and `callingMock_buildsInlineValues_whenDrawnFillReceivesCallersLazyValueBelowCalledRoot`, in the self-tests `check_reportsOtherValues_…`, `check_reportsOtherValuesThanInline_…`, `check_throws_whenSameTypesBuiltInlineDoNotCompile` and `check_reportsMockDoesNotCompile_…` (a compile of each module and a probe link per path), in `drawnValueProbes_describeKnownRight_inFirstGraphOfEachProbedCell` (the known-right half, the twin's or inline's, of each drawn probe in the first graph of each of the sixty-nine probed cells), and in the cell test's first graph of each probed cell and leaf position, and of each cell, call and later variation of the fill that receives the caller's lazy value below the called type's root that states probes, and of each cell, builder and value wrapper of the fill that holds a builder of the enclosing called type, at most 204; its other tests run the tool alone.
- **Not drawn yet** (each test named here covers its shape for each caller kind): a fill of a call nested in a re-entered fill that reads what the called mocks' copies leave uncarried, the twin's error (`SafeDIToolCallingMockCrossCallReentryTests`); a fill that re-enters its called type through another public mock where the type nothing fulfills is instantiated by a sibling place's fill, by a place of the third module's type, or around or inside a call nested in another call's fill (`SafeDIToolCallingMockReentryStructTests` covers each, and each beside a `SendableInstantiator` of the called type, as `SafeDIToolSeamReenteringSendableFillTests` does for the twin); a builder of the enclosing called type held on a level beneath the called mock's root (`whenCalledMockBuildsTypeHoldingBuilderOfFilledType`); `@Sendable` places outside the shape whose fill reads the called type's received value and the `SendableLazilyInstantiated` places of block `1090..<1120`, and a deferred place that forwards nothing (`Instantiator<T>`, `ErasedInstantiator<(), any P>`) outside the app-only screen's loop: elsewhere a plain place is held by value and a deferred one forwards `id`, so for the outer seam's value, the loop through an inner seam's builder, the seam built again and the accepted shapes, forwarding and deferral change together. Each joins the cells when drawn. Nor is rule 7's second outcome: a call inside a fill that re-enters the called mock's root level, where the fill reads, only if available, a value a level between the two builds holds (an implementation of `Checkout`'s `payments` that reads `CartScreen`'s `cart` and builds `Checkout` again). Neither this draw nor the public mock corpus's re-entering fill (`HoleFill`'s lazy cycle, on `T6`'s own level, receiving nothing) draws it; `SafeDIToolCallingMockMirrorsProductionTests`' re-entry cells cover it, and drawing it needs the check to recognize the twin's `fieldOfReenteringPlace` error as rule 7's outcome, as it recognizes the seam built again's. Nor are two of the fill gates' shapes (`DependencyTreeGenerator.holeTypesTheFillGatesPassUp(of:in:lazilyHeldValues:)`): two places of one hole type whose fills read different lazy values, and a call re-entered only through the fills of the calls its fills make; `SafeDIToolCallingMockMirrorsProductionTests`' `whenPlacesOfOneHoleTypeReadDifferentLazyValuesBesideTheirFields` and `whenCallReadingCallersLazyValueIsReenteredThroughAnotherCallsFill` cover them, and each joins the last block's variations with a seed range of its own. Nor is a fill that builds the called type again and reads the value only if available, less than the re-entered call's root level function takes it, where the called type holds no copy of the value (`Scope.labelsHandedToReenteredFunctions(by:)`); `whenFillBuildingCalledTypeAgainReadsLessOfValueThanReenteredFunctionTakes` covers it, and it joins the last block's variations, as a second place's fill that reads the value only if available, with a seed range of its own. The variation that draws a fill reading none of it while the caller holds it lazily (`fillReadsInstanceCalledTypeDoesNotHold`) reads the instance by value only: `whenFillBuildingCalledTypeAgainReadsNoneOfValueCallerHoldsLazily` covers the read only if available, a child of the fill building the called type again and re-entry through another call's fill.
- **Report only.** `publicMockCorpusCallingMocks_reportTwinsShapeErrors` runs only by hand: `SAFEDI_GRAPH_FUZZER_CALLING_MOCK_TWIN_REPORT=1 swift test --traits sourceBuild --filter SafeDIToolGraphFuzzerCallingMockTests/publicMockCorpusCallingMocks`. It runs each mocked consumer of the public mock corpus's accepted graphs as its twin and prints the consumers whose twin reports a shape error (`GraphFuzzerCallingMockTwinReport.shapeErrorMarkers`) or another error. It fails nothing: the rule for mirrored rejections is applied to its count before that change lands.
