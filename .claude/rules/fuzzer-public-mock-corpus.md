# Graph fuzzer: the public mock corpus

- **Public mock corpus.** The `generateMockPublic` generator feature draws a graph of its own (`GraphFuzzerPublicMockDraw`, `Tests/SafeDIToolTestSupport/GraphFuzzerPublicMocks.swift`) in place of the base graph, from streams of its own (`publicMockRandomSeedMask`; `publicMockSpellingRandomSeedMask` for R15's spellings; `publicMockRequiredParameterRandomSeedMask`, which alone decides whether a plain parameter narrower than its type's access is required, so that about one graph in ten draws `publicTierOmitsRequiredParameter`; `publicMockIsolationSpellingRandomSeedMask`, which decides whether an isolated initializer spells the `@MainActor` its type has; `publicMockErasureRandomSeedMask` for the erasures; `publicMockHoleRandomSeedMask` for the hole; `publicMockCallShapeRandomSeedMask` for the call shapes the button-up review added; `publicMockSecondCalledMockRandomSeedMask`, which in one graph in five has every consumer that reaches `T6` instantiate `T6Twin` too, a second `.public` type declared in `T6`'s file with `T6`'s properties, so that the consumer calls two public mocks of one hole type (`consumerReachesHoleTypeThroughTwoPublicMocks`); `publicMockHoleLoopRandomSeedMask`, a loop through `HoleLoop` around the hole (`holeInsideLoop`); and `publicMockNamespaceRandomSeedMask`, which declares `Space` in a file of its own that holds no SafeDI marker half the time and `Dock` `package` three times in ten and `public` inside a platform-conditioned `#if` block seven times in twenty (`dockInsidePlatformBlock`), which SafeDI reads exactly, as outside every block, so a holder in an unspelled extension of a `public` `Dock` is `public` and only a `package` `Dock` makes the public tier omit it; and `publicMockUnreadTypeRandomSeedMask`, which gives a leaf's child, three times in twenty, an only-if-available receive of a type no declaration SafeDI reads declares – a `StaticString`, its array or a tuple holding it, or `Unicode.Scalar` – which the public tier takes and the comment of a run without a target graph names: `unreadParameterType`, output `unreadTypeComment`), so the base and seam corpora are drawn as before and every finding is the feature's: a declaring module (`FuzzFeature`, package `shop`) with one to three types declared `generateMock: .public` (`T0`–`T2`) and their children (`T3`–`T5`), and a consumer in the same package (`T7` in `FuzzApp`), in another package (`T8` in `FuzzOther`), or both, each mocked, now and then `.public` itself, receiving or instantiating a leaf – or two leaves that receive a package dependency the other package cannot name (M8.9b) – and now and then building it inside a `Sendable` wrapper's type (`T9`, in graphs whose types are all `Sendable`). Indexed names and `t<index>` labels let the reversals act; each file names its module, and a file that declares no `@Instantiable` type, or a `SafeDIConfiguration.swift` in a directory of its own (so a renaming that prefixes file names keeps the name the tool reads), names itself on its second line (`GraphFuzzerFixture.fileNameMarker`). The draw: the leaf's initializer `package` or unspelled; tree types narrower than `public`; parameter types of each proof source (an `@Instantiable` type, a plain type only package initializers take, one a public initializer elsewhere takes, one only default arguments name, an allow-listed or `Swift.`-qualified type, an `@Instantiable` type in a namespace extension spelled `public`, `package` or not at all, one in an extension of an `@Instantiable` type, an extension-based one, and a package type), required or only if available; a protocol slot whose mock is a fake class in a file with no SafeDI content, extended by a `mockOnly` extension; `customMockName`; a lazily received label, now and then beside an only-if-available by-value receive; optional-typed, non-optional and closure defaults, and a child's default naming its own static member or only a package type; a `@MainActor` child whose initializer is isolated (which makes the leaf and its consumers isolated) or, in a `Sendable` graph, `nonisolated`; a holder of what the leaf's tree receives only if available, of a public type in an unspelled extension of `Dock`, a namespace declared `public`, three times in ten `package` (a consumer in another package then holds none, since its declaration could not name one), and in seven of twenty `public` inside a platform-conditioned `#if` block, which SafeDI reads exactly, so only a `package` `Dock` makes the public tier omit the holder, which a consumer instantiates, receives, holds lazily, builds under the `Sendable` wrapper, or declares before or after the leaf, now and then receiving the leaf only if available in turn; `mockConditionalCompilation: nil` in one module; and, on the spelling stream, a value `spelled<index>` in nine of R15's ten spellings (another module's type needs a module below the declaring one, which the draw lacks) as the leaf's forwarded, required or only-if-available property, its non-optional or optional default, its child's default, or a value every consumer forwards, the types it names proven `public` by an initializer no tree reaches (`SpellProver`, as `BadgeHolder` proves `Badge`), so that it reaches the public tier. On the erasure stream a consumer instantiates a leaf through an erasure (G1: M8.19, M8.20b) – a constant `AnyT<index>`, an `ErasedInstantiator`, or, where nothing its tree is handed from outside a `@Sendable` builder keeps it from compiling, a `SendableErasedInstantiator` – the leaf conforming to a protocol its module declares and the eraser a public struct that stores what it erases, so the value differential sees through it. On the hole stream (R7) a `.public` type `T6` instantiates a hole – a type no declaration of its module fulfills, proven `public` by `HoleProver` – on itself or on `HoleHost` beneath an `Instantiator`, a `LazilyInstantiated`, or a `Sendable` wrapper, declared as a class, as `Instantiator<Hole>`, as `any HoleProtocol`, or as an erasure of `HoleFill` (a constant or an `ErasedInstantiator`), now and then after a `package` and a public value its scope struct holds; a hand-written caller in a consumer module calls its public mock with a builder that ignores its scope (`publicMockCallerMarker`, which `GraphFuzzerOracle.addingPublicMockCallers` turns into a generated file the compile checks); and, while `drawsHoleConsumers` is on, consumers reach `T6`, one consumer module per graph declaring the type that fills the hole – reading nothing, a field of the scope struct, a value no field holds (so the caller passes the builder up), or closing a fully lazy cycle back through the fill with `Instantiator<T6>`. On the root-level stream (`publicMockRootLevelRandomSeedMask`), `T6`'s mock binds before its tree values its enums' root level holds: `holeSession`, of a type conforming to `Instantiable` by hand that the declaring module cannot build and each consumer module reaching `T6` builds in a `conformsElsewhere: true` extension of its own (which adds no conformance, so two modules may declare one), and `holeToken`, received only if available, which each such consumer instantiates; half the time `T6` receives `holeSession` lazily, so its root level holds the wrapper its mock binds apart, which the consumer instantiates and the fill reads (`holeRootLevelHoldsWrapper`, `holeFillReceivesRootLevelWrapper`). Where the hole is beneath a plain `HoleHost`, `T6` may instead receive `holeSession` in two forms (`HoleHost`'s `HoleSession`, `HoleSibling`'s `HoleDraft`) that its mock names apart, so `HoleHost`'s level binds its form again. A fill reading nothing its place's levels lack reads them (`holeFillReceivesRootLevelValue`, `holeFillReceivesFormBoundAgain`), and `publicMockRootLevelFailure` (`publicMockPassesUpPlaceItsRootLevelFills`) fails the graph when the consumer in the fill's module still takes a builder of `T6`'s places in its `mock(`. That mock orders the two named-apart forms by type, so moving type names reorders its required parameters, which the comparison does not sort: known issues. `public-mocks.md` lists, with the root level, the shapes it does not draw. Two in ten graphs whose hole is beneath a plain `HoleHost`, and three in ten others, draw none of these, so fills that read nothing and consumers without the extra providers stay in the corpus. On the call-shape stream a consumer outside the `Sendable` wrapper's module now and then receives the lazily instantiated `analytics` its leaf receives rather than instantiating it (EOU-1), a consumer reaching `T6` instantiates it under a second label, `t6Second`, too (D530-1), the graph's second place of the hole unless `t6Twin` is, which the name-stability oracle leaves out (`fuzzer-seam-oracles.md`), and a `mockOnly` fake, `HoleFake`, fulfills `T6`'s existential hole beside `HoleFill` or alone (D530-2), which a mock builds in its place. Each shape is a `GraphFuzzerPublicMockDrawFeature` read from the fixture with an exact pin (`publicMockCorpusDrawFeatureCounts`). Each graph also runs as its known-right path (`GraphFuzzerGenerator.knownRightPublicMockFixture(forSeed:)`: every declaration `public`, every `.public` mock `true`, so every consumer inlines), held in `GraphFuzzerToolRuns.knownRightOutcome`. Its oracles: the compile of every module with its own `-package-name`, batched by role as the seam split is (a nested file name is flattened, so the graphs of one invocation keep names of their own); acceptance (`publicMockAcceptanceFailure`: the drawn path may reject a graph its known-right path accepts only with a public mock's own errors, `GraphFuzzerOracle.publicMockOnlyErrorMarkers`, or `publicMockStaleValueErrorMarker` about `holeContext` and its `HoleLoop` in a graph drawing `holeLoopDeclaresContextAgain`, `holeFillReceivesField` and `consumerReachesHoleTypeWithFill`, and may not accept one it rejects, except a graph the known-right path rejects for a cycle the mock root's promotion would close through a hole's fulfilling type (M8.27b): the drawn path fills nothing there and passes the builder up, which compiles; a draw of that shape must exempt it in `publicMockAcceptanceFailure`); the ground truth (`publicMockAccessFailure`: every `public` or `package` declaration in generated code, across the lines its parentheses span, is no wider than each type or enclosing type it names by the access the draw gave it, `GraphFuzzerGenerator.narrowerTypeAccess`); the value differential (`GraphFuzzerOracle.publicMockValueGraph(of:)`, in `valueFailures`' batch, probing every generated mock without a required parameter on both paths, a difference being `publicMockBuildsOtherValuesThanKnownRight`) with section 5's two stated divergences exempted where the graph's leaf calls explain them (`statedPublicMockValueDivergences(in:of:)`, which reads each `mock(` or `__safeDI_mock(` call of a `.public` type in the probe's generated mock, `leafCalls(ofMockedType:in:prefix:)`): M8.32, a call passing `<label>.instance` of a wrapper its caller holds, whose leaf wraps the instance again – the re-made wrapper's node, exempt only where the instance beneath it is the one beneath the node the known-right path shares it with (`heldInstanceUnderReWrappedWrapperIsConsumers`), and the instance's early read, which the creation stamps show – and a dependency the calling module cannot construct, which each call of a public mock that builds it builds, and which is `nil` in one that receives it only if available, where the known-right path's caller builds one and shares it (every other dependency a called mock builds is built once by the caller and passed to each call, so the exemption reads "no call passes it" for "cannot construct"; narrowing it to the construction itself is a plan, not built) – one no call of the leaves on a node's path and on its first sight passes (a call passing `nil`, nothing, or the calling mock's own parameter that defaults to `nil`, which the parameterless probe leaves `nil`) and no declaration of the caller's tree (the probe's type, or `T9`) holds; any other difference fails; and rename invariance. Section 6's output features are `GraphFuzzerPublicMockOutputFeature`, read from accepted graphs' generated code whether or not the graph fails; the long run reports each count and the graphs each public mock error rejects, and checks the pinned minimum shares (`publicMockCorpusOutputFeatureMinimumShares`, the floor of each share the corpus run observed, for each feature the generated code shows), which the combine job adds up across shards. `publicMockKnownIssues` lists the label order of a `.public` consumer's surfaced parameters (`.mockParameterAndFieldOrder`), one of the base corpus's shapes – which back-edge of a lazy cycle loses its override (`.mockConfigurationFieldPresence`: one field of a configuration struct present under one naming and absent under another), in a consumer that builds a `.public` type's tree inline with a fill that closes a lazy cycle through it – and a value that two public mocks each build, which the stated divergence's exemption does not derive; the order of a module's configurations is not listed, here or in `seamKnownIssues`, since a generated file that differs only in the order of its extensions and public configurations counts as equal, across `#if` blocks of exactly one condition too. The long run also pins how many graphs each of a public mock's own errors rejects (`publicMockCorpusErrorGraphCounts`, in the order of `publicMockOnlyErrorMarkers`, then `publicMockStaleValueErrorMarker`, the corpus's `errorMarkers`, reported per shard as `errors`), which the combine job adds up, and the graphs `leafTierOmitsProvidedValue` rejects as the seam's omitted values (`publicMockCorpusOmittedValueGraphCount`, none since SafeDI reads `Dock` exactly: a consumer that holds a holder of a `package` `Dock` is in its package and reaches a tier that takes it). The seam's oracles (`differentialFailure`, `nilArgumentFailure`, `tierAccessFailure`, `omittedValueFailure`) skip these graphs.

The public mock corpus's `drawOverrideClosurePublicMockCall` (`publicMockOverrideClosureRandomSeedMask`, two graphs in five, after `drawRetentionPublicMock`) draws a call whose override member is a closure, the shape `public-mocks.md` says a calling mock offers only where it can hand the called `mock()` a builder a person writes: `OverriddenScreen`, a mocked consumer, `true` or `.public`, builds `OverriddenDetail`, a `.public` type with an `internal` initializer that builds only places of `OverriddenPlace1Api` and now and then `OverriddenPlace1Store`, so its mock takes no `SafeDIOverrides`; it now and then receives `overriddenSession`, plainly or renamed from `overriddenMainSession`; `OverriddenLive` fills the `OverriddenPlace1Api` place, reading the session, the other place, both or nothing, or nothing does and the consumer passes the place up, as it does where the fill reads a session `OverriddenDetail` does not receive. `GraphFuzzerToolRuns.publicMockOverrideClosureFailure` fails an accepted graph whose consumer's generated mock holds the member (`let overriddenDetail…: ((`) where the draw says the call cannot hand it (`overrideClosureCannotHandShapes`: a `.public` consumer passing a place up, a fill reading the other place, a fill reading the renamed session), or lacks it where the call can. With `MockParameterNode.offersOverrideClosure` returning `true` for every such node, seeds 2 and 4 (passed up), 31 (other place), 139 and 164 (renamed) fail; returning `false`, seeds 6, 25 and 36 do. Three draws in ten hold the `OverriddenPlace1Api` place as `ErasedInstantiator<(), any OverriddenPlace1Api>`, filled by `OverriddenPlace1Live` (`overrideClosureCallPlaceIsErasedInstantiator`), whose builder the closure is handed as a name, `ErasedInstantiator<…>.Builder`; where the consumer's overrides hold the member, `GraphFuzzerOracle.addingOverrideClosureCallers` writes the closure a person writes, passing each value it is handed on to `OverriddenDetail.mock(…)` under the label of its type, into a caller file the compile checks. With the override closure's parameters handed without `@escaping`, smoke seed 208 fails to compile ("passing non-escaping parameter"). Each `overrideClosureCall…` shape is a gating draw feature, at least ten accepted graphs each. The two place types share `OverriddenPlace1`, the part of a name the renaming that moves type names across wrapper names reads, so their builders keep one label order under it (`publicMockBuilderOrderReason` is the same order elsewhere). A builder with two places of one hole type is not drawn: its fills are generated per place, so the generator offers no closure for it, a gap `public-mocks.md` states.

The public mock corpus's `drawPromotedHolePublicMock` (`publicMockPromotedHoleRandomSeedMask`, two graphs in five, after `drawOverrideClosurePublicMockCall`) draws a place beneath a received dependency a public mock promotes to its root: `PromoteNode`, a `.public` type of the declaring module, builds `PromoteLeaf`, which receives what nothing in `PromoteNode`'s tree provides – `PromoteNode` itself through `Instantiator<PromoteNode>` or, in a `Sendable` graph, a `SendableInstantiator`, with `PromoteLeaf` holding the place of `PromoteApi`; or `PromoteOther`, which holds the place, by value, through an `Instantiator` or a `LazilyInstantiated`, or, in a `Sendable` graph, their `Sendable` forms – so the mock builds it at its root. `PromoteOther`'s initializer is `internal` half the time, so the mock's own tree builds it with its place. `PromoteScreen`, a mocked consumer, `true` or `.public`, builds `PromoteNode`, and `PromoteLive` fills the place, or nothing does and the consumer passes it up.
