# Public mocks and a seam's own mock: builders that take nothing

Continues `public-mocks.md`; a seam's builder struct is `seam-builder-structs.md`'s.

- **Which hole types take the struct.** Every hole type of a public mock takes the builder struct, as a seam's does (`SeamBuilderFamilies`): the `@Sendable` family, a forwarding place, a `LazilyInstantiated` on the route, and a case that holds another scope (a call's case, which returns another module's public mock's struct; a fill case, which returns the called mock's struct over the struct of the fill's own level; the mocked type's own root struct where its tree builds it again). A type that is a seam and a public mock takes the same struct in both. The mock's enums are namespaces with no case and no `@frozen`, as a seam's are (`seam-builder-structs.md`). A place beneath a received dependency the mock promotes to its root (`createMockRootScopeGenerator`) is a place like any other: the root's enum has a case for each promoted child whose tree leads to a place, after the cases of the mocked type's own properties and in the order the mock's tree first receives them (`inOrderTheMockTreeFirstReceives`), which is not always the order the root builds them in (`scopeEnumsByType`, which drafts a type's cases from its declarations and, at the mock's root, from the children it builds besides them), so `mock()` takes a builder for it, never a flat value (`SafeDIToolPublicMockPromotedHoleTests`). The case's values are what the root binds before it in build order, found by the value the root binds for the child, which is the non-optional value it builds where it promotes the child for an optional receive (`mockRootBinding(ofChild:of:)`), such as a calling mock's child built for the optional parameter of a called mock that promotes it; a promoted instantiator of the mocked type returns the root struct, as a property of its own that builds it again does, and a promoted child that is a call of another module's public mock returns the called mock's struct, as any call's case does.
- **The pair.** A tier that takes at least one such builder declares `mock()` and `__safeDI_mock(…)` (`ReservedName.publicMockFunctionName`), both with the tier's access, attributes, `mockAttributes` and isolation, and the same parameters and defaults; a tier that takes none is unchanged. `mock()` takes each such builder as its readable type (`Builder.readableParameterType`: `@escaping () -> T`, or the erased wrapper's `Builder` where every place is an erased instantiator) and its body is one call of the tier's `__safeDI_mock`, passing `.init(__safeDI_noScope: <label>)`. `__safeDI_mock`, documented "Only code SafeDI generates calls this function", takes the root struct, `SafeDIMockScope_<Stem>.__safeDI_Builder<T>`, under the tier's label and the builder's internal name, and holds the body `mock()` holds elsewhere; a wider tier's forwards to the next narrower tier's `__safeDI_mock`, passing each struct by its internal name. The body calls one member per level, as a seam's tree does. A type whose tree builds it with its hand-written mock also declares the construction function `__safeDI_mock(verbose:…safeDIBuilder:)` (`publicConstructionFunctionName(of:)`); the two are overloads told apart by the required `safeDIBuilder:` label, also for a mock with no `SafeDIOverrides` (`SafeDIToolPublicMockBuilderStructTests`). The guard hashes the struct type, so a mock that takes one gets a new guard name. The hole type's enums, payload structs and structs are `nonisolated`.
- **Calls from generated code.** Every call of another module's public mock is static (`PublicMockLevelFunctions`): one level function per level of the called mock's tree and per set of values the routes to it bind, decided when the code is generated, each returning the level's struct. A route on which no level binds a value a fill reads hands the fill the caller's, which the root level function takes (`ScopeGenerator.FillCallerReads`), so a call fills every place of a builder its routes reach or passes the builder up whole: an internal caller `.init(__safeDI_noScope: <its builder parameter>)`, a `.public` caller its own struct's member for the call. On a route to a place inside a fill of the call, a level function also takes the struct of the caller's fill level its member returns (`FillDispatcher.carriedInnerScopes`), as a seam's caller does. A call inside a fill re-enters a level function an enclosing call declares: a call of the same builder the root level function, and a case of a call of another module's public mock that holds a builder of a type whose places the enclosing call fills (`.inner`) that type's level function (`PublicMockLevelFunctions.Member.reentry`). Each hands the function what it takes of the caller's scope, read of the re-entering call's own (`PublicMockLevelFunctions.Reentry`), and the struct of each level of the caller's it takes: a call of the same builder the struct its own case's member returns, and an `.inner` case its level function's own struct of that level's member for the case, which the call takes as on any route to a place inside a fill, as the twin's call of the third module's seam does, so a `.public` caller's struct carries a route through the re-entering call (`SafeDIToolCallingMockReentryStructTests`); and a fill whose trees hold such a call takes those values from the function (`Scope`'s `callsInsideFills(of:reenter:)`). The caller's scope holds nothing the called mock binds on its way to the builder it holds, which its copy of the place leaves uncarried, so a fill that reads such a label gets the twin's error: `validateFills` judges a public mock call's fills against those copies (`calledCopyDeclarations`), not against the declarations on the path to the re-entering call, which it reads, and so the fills of a public mock call nested in such a fill too, for each label no scope between declares, since the nested call hands them the enclosing fill's values (`SafeDIToolCallingMockCrossCallReentryTests`' `whenFillOfCallNestedInFill…`). A fill of an instantiator's place returns the wrapper's `Builder`. No call converts a closure over an enum, and nothing decides at run time whether to pass a place up. A call's override closure is handed what the called `mock()` takes, or is not generated (`public-mocks.md`, "An override closure for a call of another module's public mock"). Over a level that reopens in a loop, the reopened level re-enters the first opening's function; a fill that reads a label the loop declares again stays rejected (`declarationBoundOnCycleReentry`).
- **A lazy value a call hands over.** A public mock that takes a builder struct, so has a function only generated code calls, takes in that function the wrapper of each value its tree receives as a `LazilyInstantiated` or `SendableLazilyInstantiated` and `mock()` takes by value (`PublicMockParameter.generatedOnlyWrapper`, from `ScopeGenerator.generatedOnlyWrappers(of:parameters:parameterNames:)`): under the name the body binds the wrapper by (`session session_lazilyInstantiated: LazilyInstantiated<Session>`), optional where `mock()` takes the instance optionally, and, for a wrapper the mock builds when passed `nil`, as `LazilyInstantiated<T>? = nil` under the parameter's name, which the body binds in place of the one it builds (`let session = session ?? LazilyInstantiated<Session>(__safeDI_session)`, `PublicMockEmission.wrapperParameterNames`). `mock()` passes `LazilyInstantiated<T> { value }`, or maps an optional, so its signature and a person's call are unchanged; the guard hashes the wrapper. A generated caller's leaf receives the wrapper, so the call hands the wrapper it holds, as inline does (`SafeDIToolPublicMockCallersWrapperTests`): nothing reads the instance at the call, and each fill of the called mock's places holds the caller's own wrapper, a re-entering fill's call included, which hands the `Screen` it builds again the caller's wrapper where it receives it only if available. A call's override closure is typed by `mock()`'s parameters (`PublicMockCall.PassedParameter.mockParameterType`): it is handed the wrapper's instance (`.instance`, or `(x as LazilyInstantiated<T>?)?.instance` where the call passes the wrapper optionally, whose binding may be optional or not), read only when a test sets it, and it is offered only where each value a fill of the call reads is one `mock()` takes in that form (`publicMockOverrideBuilders`), so a fill that reads the caller's wrapper gets none. Deliberate gaps, commented at `generatedOnlyWrappers(of:parameters:parameterNames:)` and at the bindings in `generateMockRootCode`: where the tree also receives the instance by value, the body reads it from the wrapper at its top (`let session = session_lazilyInstantiated.instance`), as the call read it before, where inline reads it when that receiver is built; an instance the mock wraps in both kinds of wrapper, which no caller holds under one label, or that defaults to a hand-written mock, is taken by value as before; and a mock with no builder struct has no such function, so a call of it hands the instance (`<label>.instance`). The graph fuzzer's M8.32 (`isEarlyReadHeldInstance`) covers those early reads; the value comparator compares a wrapper the called mock makes again by its instance, the caller's. A seam's generated-only initializer takes such a value deferred (`SeamSignature.Parameter.Deferral`). Closing the gaps means every tier takes received values deferred from generated callers by the seam's rule, without adding an availability requirement.
- **The caller's own value.** The called mock's root binds each received value a call hands it from the caller's scope (a parameter of `mock()`, or a dependency it builds where the caller passes `nil`; `SeamSignature.Hole.Field.isBoundByPublicMockRoot`), and that copy is the caller's own, as a seam's deferred parameter is: a fill whose nearest declaration of the label is that copy at every place of its case that carries a field of it reads the caller's declaration (a place that carries none has its fill read the caller's declaration already: no level on its route holds the label, or the place is inside a `@Sendable` function and the copy is bound outside it, `UncarriedDeclaration.isBoundFromCallersArgument`, whether the called type's tree receives the value outright or only if available), so its tree holds the caller's `LazilyInstantiated` itself, as inline and the twin do, and no level function takes the value (`Scope`'s `callersOwnLabels(amongLabelsOf:at:reading:handedFrom:by:)`). The caller's declaration is a scope of its tree, or its mock root's binding where that is the root's one declaration of the label, under the label: a dependency the mock promotes, as for a mocked type between the value's owner and the call (`NearestDeclarations.markBoundUnderLabelByRoot`). Where the copy does not provide every form the fill reads, such as the caller's `LazilyInstantiated`, and no call inside the fills re-enters the called mock, two more labels are the caller's own (`Scope.CallersOwnLabels`): a label the case's payload carries, on the called mock's root level, so the fill binds nothing of it from the payload and reads the caller's wrapper and its instance (`SafeDIToolCallingMockMirrorsProductionTests`' `whenFillReadsBoth`); and a label whose nearest declaration is the caller's mock root's binding of a value its tree receives, which the mock can name apart (`session_lazilyInstantiated` beside the instance `session` it takes, a label it promotes in two forms, or one a default-valued parameter of `mock()` keeps; `NearestDeclaration.isBoundByMockRoot`), where one property the root binds provides every form the fill reads: the fill binds the label to the name the mock binds that property under (`ScopeGenerator.FillPlaceBindings.rootBindingNames`; `whenFillReadsWrapperCalledMocksCopyLacks`). A stated divergence, as on a public mock's root level (`public-mocks.md`): where that property is the wrapper the mock makes of the instance `mock()` takes and the fill also reads the instance, the fill reads it through the wrapper, which then reports its instance read where the mock built inline, which reads the parameter, does not; the instance is the same. Any other label keeps its field, and the levels on each route hand the fill the field: a level of the called mock that declares the label again hands its own value, which inline reads there; a route on which no level binds the label hands the fill the caller's, which the root level function takes ("Calls from generated code"). A level that binds the label in a form that does not provide the one the fill reads is production's hidden-receive error, and a value the case's type builds after the place is production's error too (`SafeDIToolCallingMockCrossCallReentryTests`' `whenCalledTypesLevelBindsValueByValue…` and `whenCalledTypeBuildsValueFillReadsAfterThePlace`), so no level function hands a fill a form it does not read. `DependencyTreeGenerator.holeTypesTheFillGatesPassUp(of:in:)` passes two shapes up whole, every place of the hole type, before any fill is generated, where a level function could not hand each route's fill what the twin hands it, a difference contract rule 7 lists (`seam-and-mock-contract.md`): places of one hole type whose fills read different `LazilyInstantiated` or `SendableLazilyInstantiated` values beside their fields, as one beneath a level that declares the label again and another the copy reaches; a called type whose fill's tree calls its public mock again, or one whose builders reach its places, itself or through the fills of the calls it makes (a fill that calls a second called type whose own fill calls the first, `whenCallReadingCallersLazyValueIsReenteredThroughAnotherCallsFill`), where a fill of one of its places reads such a value beside its place's fields (`SafeDIToolCallingMockMirrorsProductionTests`' `generate_passesPlaceUpWhole_…` and `generate_passesBothPlacesUpWhole_…`). The first gate also passes up some places whose fills would read what inline reads, as a calling mock passed them up before its fills read the caller's values, the stated cost of one rule: where the called mock holds no copy of the value, so each route hands its fill the wrapper inline reads, and where the places hold the hole type in two builder forms, one of them an `ErasedInstantiator` (`whenPlacesOfOneHoleTypeReadDifferentLazyValuesBesideTheirFields`' `levelBesidePlaceWithoutCopy` and `levelBesideErasedPlace`). A fill whose tree calls a public mock that then passes a builder up is not filled either. Each gate decides per called type and hole type for the whole module, so every mock of the module that calls the type passes the place up, a `.public` mock included. An unreal shape, not a defect, keeps a gate's place passed up: a mocked type whose mock promotes a label in two forms that no one property provides, `LazilyInstantiated<Log>` and `Instantiator<Log>`, where one fill reads both; no declaration above the mocked type in a production tree provides both forms, so no tree it is built in compiles. Lifting the gates means each route of a re-entered call decides again whether it fills the place, with the builder declared wherever a route passes it up; a release that fills these places keeps `mock()`'s builder parameter, defaulted, so tests that pass one keep compiling. Where a call inside the fills re-enters the called mock's root level function, the label is the fill's field again (`Scope`'s re-entering call) and a parameter of the root level function, which each call hands its own nearest declaration (`PublicMockLevelFunctions.Reentry`), the one inline reads at the places that call reaches. A fill whose tree holds such a call takes each value the re-entered function takes non-optional, as the function takes it, whatever its own tree reads of it (`Scope.labelsHandedToReenteredFunctions(by:)`): where the called type holds no copy of the value, a fill that reads it only if available, or not at all while the caller holds it lazily, would otherwise hand the function an optional or the caller's wrapper (`whenFillBuildingCalledTypeAgainReadsLessOfValueThanReenteredFunctionTakes`). One known defect remains there, where the caller holds the value lazily and the called type holds no copy of it: a fill that reads none of the value captures the caller's wrapper where the re-entered function takes the value or its optional, which does not compile, both where the fill builds the called type again itself or through a child of its tree and where it re-enters through another call's fill a function that takes the value only if available (an optional parameter, which `labelsHandedToReenteredFunctions(by:)` skips). Plan: see the ruling.
- **A seam's own internal mock** (`MockRootParameters.SeamMockBuilder`, `ScopeGenerator.seamMockBuilders`) takes, for each hole type and family whose places its tree cannot build, the builder the seam's readable initializer takes, in place of those places' flat parameters: its type is the seam's (`DependencyTreeGenerator.builderForm(ofPlaceProperties:)`, `readableBuilderType`: `() -> T`, `@Sendable` for a place built in a `@Sendable` function or held in a `Sendable` wrapper, or the wrapper's `Builder` where every place is an instantiator), and it is labeled from what it builds as a seam's builder is (`DependencyTreeGenerator.stems(of:)`), with `_` appended while another parameter of `mock()` has the label, so the seam's own labels and guard never move; it is listed among the flat received parameters by label. Each type that instantiates a place calls it once per build and binds the value under the place's label, or builds the place's wrapper (`LazilyInstantiated`, an instantiator) around it (`SendableAutoclosureParameter.binding`); where a name the tree binds at any level has the builder's label, `mock()` first binds it to a name apart (`let <name> = <label>`). It has no struct and no `__safeDI_mock`: no generated code calls an internal mock. A place reached through another module's public mock is passed up as that mock's readable builder; one that a `@Sendable` builder function captures, such as a call of the mock inside a `SendableInstantiator` the internal mock builds, is of the `@Sendable` family and taken `@Sendable` (`passedUpBuilderFamilies`), so it is one builder, `<stem>SendableBuilder`, with the `@Sendable` builder its calls pass up for the same hole type (`seamMockBuilders`, `generate_takesOneSendableBuilderForEveryPlace_whenInternalMockPassesUpPlacesOfMockItAlsoBuildsInASendableFunction`). A known gap, planned for 2.3.1 as one builder per family across mixed forms: where the builders of one hole type and family are passed up in different forms that forward the same value (a plain place beside an erased instantiator that forwards `()`, or beside an `Instantiator` of a type that conforms to `Instantiable` by hand, from two calls or from a call and the seam's own places), an internal calling mock takes one builder per passed-up form where its twin takes one per family; its values are right, and the cells that cover it compare only values (`SafeDIToolPublicMockNestedBuilderTests`' `generate_buildsTheInlineValues_when…`, comment at `seamMockBuilders`). An internal mock of a type that is not a seam keeps its flat parameters, which are API, but for a call of a switched public mock inside it, and its fills take builders for what they cannot build: each place inside a fill of a call of another module’s public mock that no declaration the module sees fulfills, spelled as a hole can be (`canBeHole`), is a place of a builder of its own (`ScopeGenerator.FillPlace`, `fillPlaces(insideSendableFunction:)`), joined by family with the type’s own places where it is a seam, labeled and named apart from the fills’ declarations in the same way, and bound by the type in the fill that instantiates it (`FillPlaceBindings`, through `prepareFillCode`), so the mock fills that call’s place where its twin does (`DependencyTreeGenerator.holesFilled`). A deliberate gap from the twin, which takes one builder per hole type: a type that is not a seam takes a flat parameter for the same type its own tree instantiates outside every fill, and a builder only for the places inside fills; and where it builds a seam itself whose hole nothing fulfills, a flat parameter for the hole, while a seam a fill builds takes a builder (comments at `seamMockBuilders`' call and `fillPlaces(insideSendableFunction:)`). A fill whose tree instantiates, with no declaration fulfilling it, a type spelled as no hole can be (a closure, tuple, array or dictionary) is production's error, `noInstantiableFound` at that property, which both kinds of calling mock report where a mock's tree reaches the call (`holesFilled`' `typesNoDeclarationCanFulfillByCalledType`, `validateFillsInstantiateOnlyWhatCanBeFulfilled`), in a build that compiles the generated mocks only (`compilesGeneratedMocks`, as for a hand-written mock's unfulfilled parameter in `validation-boundaries.md`): a release build compiles no mock, and generates the place passed up, with no error (`generate_generatesMockWithoutTwinsError_whenBuildLeavesMockConditionInactive`). A debug build whose integration does not report `DEBUG` (SwiftPM's native backend) compiles that mock, with the place passed up, where an integration that reports `DEBUG` gets production's error (the same test's debug cases, and the calling-mock draw's last block). `query needs` reports each builder as a required parameter (`DependencyTreeGenerator.requirements`).
- **Graph fuzzer.** The hand-written caller (`GraphFuzzerOracle.addingPublicMockCallers`) rewrites `{ _ in value }` to `{ value }` where `mock()` takes a builder that takes nothing, reading the type from the generated file, and the retention probe (`handWrittenRetentionProbe`) does the same for `RetainHome`.
