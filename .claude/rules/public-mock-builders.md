# Public mocks and a seam's own mock: builders that take nothing

Continues `public-mocks.md`; a seam's builder struct is `seam-builder-structs.md`'s.

- **Which hole types take the struct.** A public mock's builders of one hole type, both families together, take the builder struct by a rule of their own, `SeamBuilderFamilies.publicMockTakesBuilderStructs(of:holesBySite:)`, never the seam's `declaresBuilderStructs(of:)`: no place they reach is built inside a `@Sendable` function (the hole type has a `SafeDISendableMockScope_` enum), forwards a value (`Hole.forwardedType`; an `ErasedInstantiator<(), B>` forwards nothing and takes the struct beside a plain place), or is held in, built beneath, or handed a `LazilyInstantiated`; and no case holds another scope (a call's case holding another module's public mock's enum, a fill case, or the mocked type's own root enum where its tree builds it again). Every other hole type keeps main's closure over its enum, in the mock's module and at every call; a calling module computes the called mock's signature through the same function, so nothing in a `.safedi` file changes. A type that is a seam and a public mock can so take the struct in its seam and keep the enum in its mock (the `@Sendable` family, a lazy value on the route, a scope a case holds): a deliberate difference, commented at `shapedBuilders` and at `publicMockTakesBuilderStructs`, until the mock's rule takes those too. The mock's enums keep their cases and `@frozen` where they declare the struct (`seam-builder-structs.md`), because the calls below still build and switch over them.
- **The pair.** A tier that takes at least one such builder declares `mock()` and `__safeDI_mock(…)` (`ReservedName.publicMockFunctionName`), both with the tier's access, attributes, `mockAttributes` and isolation, and the same parameters and defaults; a tier that takes none is unchanged. `mock()` takes each such builder as its readable type (`Builder.readableParameterType`: `@escaping () -> T`, or the erased wrapper's `Builder` where every place is an erased instantiator) and its body is one call of the tier's `__safeDI_mock`, passing `.init(__safeDI_noScope: <label>)`. `__safeDI_mock`, documented "Only code SafeDI generates calls this function", takes the root struct, `SafeDIMockScope_<Stem>.__safeDI_Builder<T>`, under the tier's label and the builder's internal name, and holds the body `mock()` holds elsewhere; a wider tier's forwards to the next narrower tier's `__safeDI_mock`, passing each struct by its internal name. The body calls one member per level, as a seam's tree does. A type whose tree builds it with its hand-written mock also declares the construction function `__safeDI_mock(verbose:…safeDIBuilder:)` (`publicConstructionFunctionName(of:)`); the two are overloads told apart by the required `safeDIBuilder:` label, also for a mock with no `SafeDIOverrides` (`SafeDIToolPublicMockBuilderStructTests`). The guard hashes the struct type, so a mock that takes one gets a new guard name. The switched hole type's enums, payload structs and structs are `nonisolated`; a kept one's get none.
- **Calls from generated code.** A caller writes each dispatcher of a call in enum form, per route, when the tree is built (`FillDispatcher.returnsBuilderStruct` is false where `decidesPerRoute`), and `builderCallArguments` records beside the enum-form argument the struct a builder that takes one would be passed (`BuilderCallArgument.PublicMockBuilderStruct`). At code generation (`ScopeGenerator.staticPublicMockCallKeys`), a builder whose every place the call fills on every route, with no optional dispatcher or fill parameter, no case that finds a value nowhere, every value handed on in its field's own form, and no override closure that takes the builder, is passed its root level function called: its dispatchers are copied as the struct's levels (`fillDispatchers(_:returningBuilderStructsOf:)`), declared by `structDeclaration`, with the parameters `dispatcherParameters(of:fillReads:)` gives a seam's caller. Dispatchers an enclosing call declares and a nested call reuses get one decision: the struct's levels only where every call that uses them qualifies. A builder that reaches a place held in an instantiator has no such candidate and always converts, a deliberate gap, commented at the candidate and where a fill is told to return the wrapper's builder, until the slice that makes every public mock call static: a static call's level function would hand back the wrapper's `Builder`, which a fill built before the decision does not return. Every other call of such a builder passes a pass-up, a route closure or the caller's own parameter through `builderStructConversion`, as a seam passes a kept seam's closure, with `passUp` spelled through `FillDispatcher.passUpParameterName`. A call's override closure is handed what the called `mock()` takes, or is not generated (`public-mocks.md`, "An override closure for a call of another module's public mock"). A caller's own parameters do not change. Over a level that reopens in a loop, the conversion declares one function per level a route first opens, so the closure over the enum is handed the first opening's values, as the mock's body re-enters the first opening's function; a fill that reads a label the loop declares again stays rejected (`declarationBoundOnCycleReentry`).
- **A seam's own internal mock** (`MockRootParameters.SeamMockBuilder`, `ScopeGenerator.seamMockBuilders`) takes, for each hole type and family whose places its tree cannot build, the builder the seam's readable initializer takes, in place of those places' flat parameters: its type is the seam's (`DependencyTreeGenerator.builderForm(ofPlaceProperties:)`, `readableBuilderType`: `() -> T`, `@Sendable` for a place built in a `@Sendable` function or held in a `Sendable` wrapper, or the wrapper's `Builder` where every place is an instantiator), and it is labeled from what it builds as a seam's builder is (`DependencyTreeGenerator.stems(of:)`), with `_` appended while another parameter of `mock()` has the label, so the seam's own labels and guard never move; it is listed among the flat received parameters by label. Each type that instantiates a place calls it once per build and binds the value under the place's label, or builds the place's wrapper (`LazilyInstantiated`, an instantiator) around it (`SendableAutoclosureParameter.binding`); where a name the tree binds at any level has the builder's label, `mock()` first binds it to a name apart (`let <name> = <label>`). It has no struct and no `__safeDI_mock`: no generated code calls an internal mock. A place reached through another module's public mock is passed up as that mock's readable builder. An internal mock of a type that is not a seam keeps its flat parameters, which are API, but for a call of a switched public mock inside it. `query needs` reports each builder as a required parameter (`DependencyTreeGenerator.requirements`).
- **Graph fuzzer.** The hand-written caller (`GraphFuzzerOracle.addingPublicMockCallers`) rewrites `{ _ in value }` to `{ value }` where `mock()` takes a builder that takes nothing, reading the type from the generated file, and the retention probe (`handWrittenRetentionProbe`) does the same for `RetainHome`. The output features `.generatedOnlyMockFunction`, `.consumerPassesLevelFunctionsStruct`, `.consumerConvertsClosureOverEnum`, `.consumerConvertsOverReopenedLevel` and `.holeLoopBuilderOfBuilderStruct` count the new shapes; the seam corpus counts a seam's own mock that takes a builder (`GraphFuzzerSeamOutputFeature.seamOwnMockBuilder`, the `seam-mock-builders` report line, floor ten in the combine job).
