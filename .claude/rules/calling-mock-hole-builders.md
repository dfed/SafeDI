# A calling mock's builders for the places its calls fill

Continues `public-mock-builders.md`. Kept apart so that the generator files this does not govern do not load it.

- **Optional builders for filled places.** A calling mock takes one optional builder, `(() -> T)? = nil`, per hole type and family whose places its calls of other modules' public mocks fill, at the mock root's level or inside fills (`ScopeGenerator.FilledCall`, `filledFamilies(of:)`), so the builder a test writes is never ignored. Family: a filled builder's is the one a passed-up builder of it would take, `@Sendable` where the called builder is or the call is made inside a `@Sendable` function. Labels: the label a required builder of the hole type would take, from `stems(of:)` over every hole type of the mock's builders in a lifted gate's order (own places, fill places, then passed-up and filled builders in the sorted order of the properties they would be received as), unless that pass renames a required builder's stem, when the optional ones are named among themselves (`stemsOfOptionalBuilders`); claimed after every required label, so no existing label moves, and `_` on collision. The one check site is the call's struct (`FillPlaceBindings.HoleBuilder.structValue`): `<name>.map { .init(__safeDI_noScope: $0) } ?? <root level call>`, read at the root-level call and inside fills (`constructionArgumentList`); level functions, dispatchers and inlined fills gain nothing. An override of the called type is handed `{ if let <name> { <name>() } else { <fill>(…) } }` (`overrideValue`). A call that re-enters an enclosing call (a call inside a fill whose argument holds no builder struct and names the enclosing call's root dispatcher, `FilledCall.reenteredBuilders`) reads the enclosing call's builder for that argument, in its family, or the `@Sendable` twin where the re-entering call is inside a `@Sendable` function; within one family the read changes no value, since the enclosing fill runs only where the builder is `nil`, but every place of the hole type then reads it the same way. An override of a called type wrapped in a builder (`PublicMockOverrideBuilder`'s wrapper case) is handed `<name> ?? <call>` (`wrapperBuilderValue`). No adapter: a place whose builder takes a value is an instantiator of a type that conforms to `Instantiable` by hand, which no type a caller declares can fulfill, so no call fills it (comment at `structValue`). Inline-built public mocks: where the calling module can call a public mock's initializer and construct its tree, it builds the mock inline, and each place of that tree whose type the public mock's own module sees nothing fulfill (a hole a call would hand the builder) reads the builder of its family: a place built by value at its construction (`ScopeGenerator.holeBuildersByInlinePlace`, keyed by node in `FillPlaceBindings.holeBuildersByInlinePlace`; `HoleBuilder.inlinePlaceValue`), `if let <name>, <override> == nil { <name>() } else <construction>`; a place held in an instantiator or `LazilyInstantiated` where the wrapper is made, `<Wrapper>(<name>)` (`generateInstantiatorBinding`); a place inside a fill, which no override reaches, in the fill's code (`holeBuildersByInlinePlaceInFills`, keyed by scope generator; `propertyCode`, `Expression.holeBuilderRead`). An override of the place still wins, as it wins over a call's builder, and a required builder is read wherever no override is set. Its hole type is the one its declaration instantiates, a `fulfilledByType:` included, as a seam keys its holes. A `.public` mock takes a required builder as a struct with a member per place its calls hold and none for an inline place, so a module calls, rather than builds inline, another module's public type that one of its `.public` mocks reaches and whose tree holds a hole of that type's module (`DependencyTreeGenerator.publicMockCalls`), for every mock of the module; the values are those of the tree built inline. Not where a fill of such a place receives a value the tree declares, which a call may not hand it: the type stays inline, the `.public` mock filling the place; nor under another mock condition (`PublicMockCall.mockConditionsAgree`). Tests: `SafeDIToolCallingMockInlineHoleBuilderTests` (each form, inside a fill, internal and `.public` callers), `SafeDIToolCallingMockHoleBuilderShapeTests`' `whenAnotherCallPassesSameHoleTypeUp` (a required builder, for an internal mock, a `.public` one and a seam's public mock). The join: a family the internal mock also takes a required builder for (a passed-up place, its own places, a fill place) adds no parameter; its calls hand `.init(__safeDI_noScope: <required>)` and overrides `{ <required>() }`. A public mock takes each as a `PublicMockParameter` of `Role.optionalBuilder` after its required builders, on `mock()` and `__safeDI_mock` (under an internal name apart from every name of its tree and fills); a joined one appears on `__safeDI_mock` only, under the `_` label, and `mock()` passes the required builder to it. Generated callers never pass one (`PublicMockCall` drops the role), so the called mock's fills build those places. The per-root channel is `FillPlaceBindings.holeBuildersByCall`, keyed by the call's generator, so fill code is cached by (`propertiesGeneratedLater`, `FillPlaceBindings`). `query needs` lists none. A B5 exception: in the fallback a later gate lift can relabel an optional builder from `x_` to the stem the union pass gives.
