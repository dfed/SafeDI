# Seams: carriers and run structs

Continues `seam-builder-structs.md`, whose builder structs a carrier replaces.

**Carriers.** A seam's hole type whose routes lead through no fill, of a seam that makes no call re-entering an enclosing fill, hands its levels to its builders as carriers (`SeamBuilderFamilies`: its root enums are named `SafeDICarrierScope_<Stem>` and `SafeDISendableCarrierScope_<Stem>`, `ReservedName.seamCarrierScopeTypeNamePrefix`, names no generated code spells, which only key the levels); every other seam hole type, and every public mock's, keeps the builder structs below. Each level of such an enum is `nonisolated public final class __safeDI_<Stem>Carrier<__safeDI_Built>`, `__safeDI_<Stem>SendableCarrier` (`: Sendable`) for the `@Sendable` family, `_<Type>` appended for a level nested by type (`ReservedName.seamCarrier(ofEnum:)`; `levelType(ofEnum:built:)` spells a level's type as a carrier or a builder struct, qualified by the seam where a caller spells it, and `namesLevelType` reads either back), declared side by side in the seam's extension (`scopeEnumDeclaration`): no namespace enum, no payload struct. A carrier has one `public let` member per case, named as the case, which returns what the builder struct's would (the built type, the erased wrapper's `Builder`, or the held level's carrier); its memberwise `public init`, and `public convenience init(__safeDI_noScope __safeDI_builder:)`, which hands the memberwise one an adapter per member ignoring its arguments (`{ _, _ in … }`). That initializer, a builder struct's too, delegates to the memberwise one. It is plain, never `@_alwaysEmitIntoClient`: a carrier that passes another module’s places up calls that module’s fallback, so every module above a seam would read and check the fallbacks of every seam module beneath it (sixteen in a chain compiled 14% slower in debug and 27% slower in release), and Swift emits neither the body nor the symbol of an effectively `internal` one into a module that imports it `@testable`. A fallback nothing calls still costs its module’s compile; the way out is not declaring it, not emitting it elsewhere. A case whose level binds values takes them as arguments, a deferred parameter's as its memo; a `@Sendable` carrier's members take none, as its enum's cases carry none. A nested level, or an inner seam's root a call passes up (`.inner`), that is handed no value and is in no loop of levels (`ScopeEnum.Case.isLetChildOfCarrier`: not `indirect`, not in its enum's own strongly connected component, and in the `@Sendable` family only a `Sendable` child) is a `let` of the child carrier itself, not a closure, formed where its parent is formed; the seam's tree reads it (`ValuesBinding.isLetChild`), as does a call whose own case is one, each decided from the seam's settled enums where the member is spelled (`SeamHoles`, so a level re-entered or in a cycle, `indirect` by then, is called: a decision taken while the enums were still settling read a call's member as a property), and a caller's level function passes the next level's function called, with no closure around it (`FillDispatcher.Case.isLetChild`).

**Positional levels and run structs.** A carrier level's values are handed positionally or in run structs (`SeamCarrierValues`, the one place that decides how, which the carrier's declaration, the seam's tree and the caller all read). A level takes its values positionally when its longest case takes at most `SeamCarrierValues.maximumPositionalValues` (8) and every value's access reaches the seam's type, which caps a carrier's `public` members (`positionalLevels(of:memberAccess:)`); otherwise it takes run structs. Why: a struct per run costs narrow levels more than positional arguments do, while positional arguments repeat every value at every case, which grows with the square of a wide level; and a value narrower than the member cannot cross it positionally. The seam's own module decides it, in `SeamBuilderFamilies.shapedBuilders`, and records it on each of the level's enums (`ScopeEnum.takesValuesPositionally`, kept in the `.safedi`), so a caller reads the decision and never computes it from what it sees of the seam's types. A level is keyed by the seam and the type it describes, whatever hole type its enum is of (`SeamCarrierValues.level(ofEnum:)`: `__safeDI_` and the described type, nothing for the seam's root), and the values of its cases are prefixes of one sequence by construction: `SeamScopeEnumsByType` computes what a type binds once per type (`LevelsOfEveryHoleType.declarations(of:as:…)`) and cuts every case of every hole type from it, a case in a loop of builders ending at the loop's first member, since a loop is built as one unit. A level of run structs is cut into runs at the lengths its cases take: a run ends at every length. Each run is `nonisolated public struct __safeDI_<Level>Values<end>` (`structType(ofLevel:end:qualifiedBy:)`), declared before the carriers in the order the enums first meet their levels, then run order, never by name, which the rename oracle catches (`declarations(fieldsByLevel:typesDeclaredEscaping:indent:)`), holding `previous`, the run before it, and its own fields, each at its own access, so a value narrower than the carrier never crosses a `public` member positionally (P1-CLASSES-REVISED-UNDER-E: one `public` carrier class). A member takes the struct of the longest run its case's values end (`use(ofLevel:count:)`, `Use.structEnd`) and any value after it positionally (`Use.extras`, empty when every length ends a run); The seam's tree binds each run's struct once in the body that binds the level, `let __safeDI_<Level>_values<end> = __safeDI_<Level>Values<end>(previous: …, …)` (`bindingName(ofLevel:end:)`, `ValuesBinding(formingRunOf:end:fields:previousName:)`, `formsRunAfter`), at the path of the case that takes the fewest values of at least the run's end, in the order the body builds them (`SeamHoles.init`'s takers; the path's spelling only breaks a tie no shape reaches), before that path's member binding, or before the place's own call (`SeamHoles.carrierSite(at:)`, `CarrierSite.formations`, `siteCarrierUse`); the member is then called with the struct's binding and the extras (`SeamHoles.carrierArguments(of:use:…)`). A caller's closure for a member takes the struct as `scope` (or the dispatcher's payload name) and each extra as that name joined with its label (`SeamHoles.argumentName(of:inPayloadNamed:)`), and reads a field through as many `.previous` as runs lie between (`Use.read(ofFieldAt:of:inPayloadNamed:bindingMemo:)`), a deferred field's instance where it reads the value (`argumentRead`); a fill of a carrier's place takes the same parameters (`fillCarrierUse`, from `CalledBuilders.carrierUse(ofPlace:)`) and binds what it reads from them. So a member takes one argument however many values its level binds, a run's fields are spelled once per level, and values that grow with a level's cases grow the code linearly.
