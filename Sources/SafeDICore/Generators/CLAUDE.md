# Generators

`DependencyTreeGenerator.swift` and its `DependencyTreeGenerator+*.swift` files, one per concern, build and validate the production trees and the mock roots; `ScopeGenerator.swift` emits the code. By file: `+ScopeMapping` (`createTypeDescriptionToScopeMapping`), `+FulfillmentValidation` (`validatePropertiesAreFulfillable`), `+CycleValidation`, `+DeclarationValidation`, `+Errors` (`DependencyTreeGeneratorError`), `+MockOrchestration` (`generateMockCode`), `+MockRootPromotion` (`createMockRootScopeGenerator`), `+PublicMockCalls`, `+SeamDriver`, `+SeamTreeReads` (what a seam's signature reads of its tree, beside the facts' value), `+Constructions`, and `+Requirements` (`query needs`). The rules in `.claude/rules/` load as you read files here; the root `CLAUDE.md` lists them by topic. Grep loads none of them: when you change a generator from a file elsewhere, read the ones for its topic first.
