## Tree order (H3)

No change to creation, sibling or parameter order in generated output since 2.2.0, outside seams and public mocks, which are new. Evidence: every commit body in `2.2.0..d4131776` (241 commits) was searched for order, sort and sequence changes; the only order changes (#689, #742, and the label-sorted seam pass-throughs and builders) are in seams or loops new in this release. Check 6’s comparator records each value’s creation stamp, and its 5,000 seeds against 2.2.0 found 11 value differences, all from the nearest-declaration fixes (#533, #571, #572), none from order. So the notes have no order line.
