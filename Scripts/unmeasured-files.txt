# is neither recorded by the Linux or macOS test run's coverage report nor listed here, so code cannot leave

# get a record, or no longer exists, so this list cannot go stale.

Plugins/SafeDIGenerator/SafeDIGenerateDependencyTree.swift: the build tool plugin's entry point, which imports PackagePlugin, which no test target can link
Plugins/Shared.swift: compiled only into the plugins, and imports PackagePlugin, which no test target can link
Sources/SafeDI/Decorators/Forwarded.swift: macro declarations only, which compile to no executable code
Sources/SafeDI/Decorators/Instantiable.swift: macro declarations only, which compile to no executable code
Sources/SafeDI/Decorators/Instantiated.swift: macro declarations only, which compile to no executable code
Sources/SafeDI/Decorators/Received.swift: macro declarations only, which compile to no executable code
Sources/SafeDI/Decorators/SafeDIConfiguration.swift: macro declarations only, which compile to no executable code
Sources/SafeDICore/Errors/DiagnosticError.swift: a protocol declaration only, which compiles to no executable code
